# PetLog - Pet Activity Logger

Quick and simple pet activity logging with real-time sync between household members.

## 🚀 Quick Start (On Your Chromebook)

**One command to run everything:**

```bash
cd ~/Pet-App/Pet-App-claude-pet-activity-logger-Etaqb && bash setup-and-run.sh
```

Then scan the QR code with Expo Go on your iPhone!

## ✨ Features

- 🐕 Log activities: Poop, Pee, Food, Sleep
- 📱 Real-time sync between devices
- 💬 iMessage-style activity feed
- 🔥 Firebase backend
- ⚡ Fast, simple UI
